# Hi, I'm Jordan 👋

**Full-stack engineer & Technical Lead** — I build the whole thing: frontend, backend, database, and the server it breaks on at night.

</div>

I'm a Technical Lead at [KrestDev](https://krestdev.com/), moving between architecture diagrams, actual code, and infrastructure. React and Next.js on one side, Node.js and NestJS on the other, Docker and CI/CD holding it all together.

Most of the interesting problems I run into aren't "can this be built" — they're "will this still work in six months, under real traffic, with real users who don't read the docs."

I've spent the last few years building for the Cameroonian market specifically: **Mobile Money instead of Stripe, XAF instead of USD, WhatsApp instead of email** — because that's how people here actually get things done. I'm not chasing every new framework; I care more about whether something is well-built than whether it's trendy.

Working in French and English, based in Douala, Cameroon 🇨🇲.
