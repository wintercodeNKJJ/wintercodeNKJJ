SHEET 02 / 06 — APPROACH

Built for real conditions, not the tutorial

I've spent the last few years building for the Cameroonian market specifically — which means designing around Mobile Money instead of Stripe, XAF instead of USD, and WhatsApp instead of email, because that's how people here actually get things done. It's a different set of constraints than most tutorials prepare you for, and I've learned a lot from working inside them.

I'm not chasing every new framework — I care more about whether something is well-built than whether it's trendy. If a project needs a document workflow system with 100+ endpoints and a proper permission model, or an AI pipeline that reviews its own output before publishing, I'll take the time to think it through rather than rush a version one.
